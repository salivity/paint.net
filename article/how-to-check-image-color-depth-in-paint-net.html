How to Check Image Color Depth in Paint.NET

This article explains how to determine the color depth and bits-per-channel (BPC) of an image using Paint.NET, alongside the application's internal color handling rules. Because Paint.NET standardizes all loaded images into a specific working color space without a traditional image properties window, identifying an image's original and export bit depth requires checking the save settings or the underlying file properties.

Understanding Paint.NET’s Working Color Depth

Paint.NET natively operates entirely in a 32-bit color space, which translates to 8 bits per channel (bpc):

  • 8 bits Red
  • 8 bits Green
  • 8 bits Blue
  • 8 bits Alpha (transparency)

Regardless of whether you open a 1-bit monochrome image, an 8-bit indexed image, or a 24-bit RGB photo, Paint.NET automatically promotes the canvas to 32-bit ARGB upon import. Paint.NET does not currently support high-bit-depth editing formats, such as 16-bit or 32-bit per channel (BPC) HDR images.

Method 1: Check Color Depth via the Save Configuration Dialog

While Paint.NET lacks a dedicated image information panel, you can view and test the export bit depth through the Save Configuration screen:

  1. Open the image in Paint.NET.
  2. Click File in the top menu and select Save As... (or press Ctrl + Shift + S).
  3. Choose a format that supports variable bit depths, such as PNG, BMP, or TIFF, and click Save. (Do not worry about overwriting; you can cancel after viewing).
  4. In the Save Configuration dialog box that appears, locate the Bit Depth section on the left.
  5. Review the available options:
    • Auto-detect: Automatically assesses the lowest bit depth needed to render the current canvas without quality loss.
    • 32-bit: 8 bits per channel plus transparency (RGBA).
    • 24-bit: 8 bits per channel without transparency (RGB).
    • 8-bit: Indexed color palette (256 colors).
  6. Click Cancel to close the dialog without modifying your file.

Method 2: Check the Original Image Color Depth via Windows Explorer

Because Paint.NET automatically converts images into its 32-bit workspace, the most accurate way to check an existing file's original bit depth without conversion is through Windows:

  1. Navigate to the image file on your computer.
  2. Right-click the file and select Properties.
  3. Select the Details tab.
  4. Scroll down to the Image section.
  5. Locate the Bit depth entry:
    • 24 indicates standard 8 bits per channel (RGB).
    • 32 indicates 8 bits per channel with an alpha/transparency channel (RGBA).
    • 8, 4, or 1 indicates indexed or monochrome color palettes.
