Paint.NET Levels: Input and Output Sliders Explained

The Levels adjustment in Paint.NET is a powerful tool for correcting color balance, contrast, and exposure by manipulating the tonal range of an image. This guide explains the exact functions of both the Input and Output sliders in the Levels window, detailing how each control alters pixel values and affects your final composition.

Understanding the Tonal Scale

Paint.NET measures brightness values on a scale from 0 to 255. A value of 0 represents pure black, while 255 represents pure white. Values in between represent varying shades of gray or color brightness. The Levels dialog allows you to remap these values using two primary controls: the Input sliders and the Output sliders.

The Input Sliders: Adjusting Contrast and Clipping

The Input section is typically used to increase contrast, correct under- or over-exposed images, and adjust midtone brightness. It features three controls:

  • Black Point Slider (Bottom/Left): Sets the threshold for what is considered pure black. Moving this slider up (increasing the value from 0) forces all pixels at or below that value to become pure black (0). This darkens the shadows and deepens the dark tones of the image.
  • Midtone Slider (Center): Often referred to as Gamma, this slider adjusts the distribution of midtones without changing the absolute black or white points. Moving it changes whether the midtones lean closer to shadows or highlights, brightening or darkening the overall image while preserving the extremes.
  • White Point Slider (Top/Right): Sets the threshold for what is considered pure white. Moving this slider down (decreasing the value from 255) forces all pixels at or above that value to become pure white (255). This brightens highlights and brings out detail in brighter areas.

By moving the black and white Input sliders closer together, you stretch the image's dynamic range across a narrower set of original data, increasing overall contrast.

The Output Sliders: Compressing Dynamic Range

The Output section limits the maximum and minimum brightness values that can appear in the image. Rather than expanding or shifting tones, it compresses the dynamic range:

  • Black Point Slider (Bottom/Left): Sets the darkest value the image is allowed to display. If you raise this value from 0 to 50, pure black is eliminated; the darkest pixels in the image will now only be a dark gray. This creates a faded, matte, or vintage look by lifting the shadows.
  • White Point Slider (Top/Right): Sets the brightest value the image is allowed to display. If you lower this value from 255 to 200, pure white is eliminated; the brightest pixels will now be capped at a light gray. This dims the highlights and reduces glare.

Moving the Output sliders closer together reduces contrast and flattens the image, as it restricts the available tonal spectrum between the chosen minimum and maximum thresholds.

Summary of Differences

  • Input Sliders map a specific range of original pixels to full black and full white, expanding contrast and allowing you to set clipping points.
  • Output Sliders restrict the absolute boundaries of black and white, reducing contrast and capping how dark or bright the image is permitted to be.
