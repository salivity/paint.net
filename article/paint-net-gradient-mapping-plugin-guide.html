Paint.NET Gradient Mapping Plugin Guide

Gradient mapping is a powerful color grading technique that replaces the luminance values of an image with a custom color gradient, mapping shadows, midtones, and highlights to distinct hues. While Paint.NET does not support this tool natively, the Gradient Mapping plugin created by forum developer pyrochild provides this exact capability. This guide covers how Pyrochild's Gradient Mapping plugin works, how to install it, and how to use it to color grade your artwork or photographs.

The Pyrochild Gradient Mapping Plugin

The definitive plugin for gradient mapping in Paint.NET is Gradient Mapping, which is packaged inside the popular Pyrochild Plugin Set. This plugin evaluates the brightness of each pixel on a layer and assigns it a corresponding color from a user-defined gradient. It is widely used for:

  • Creating cinematic split-toning effects (such as teal and orange looks).
  • Converting black-and-white photos into duotone, tritone, or multitone art.
  • Stylizing illustrations with unified color palettes.

How to Install the Plugin

To install the Gradient Mapping tool in Paint.NET:

  1. Close Paint.NET if it is currently running.
  2. Download the Pyrochild Plugin Set from the official Paint.NET forums.
  3. Extract the downloaded .zip archive.
  4. Locate the Gradient Mapping.dll file (along with Pyrochild.Core.dll, which is required for it to run).
  5. Copy both .dll files and paste them into your Paint.NET Effects folder:
    • Standard installation: C:\Program Files\paint.net\Effects
    • Microsoft Store version: Documents\paint.net App Files\Effects
  6. Restart Paint.NET.

How to Color Grade Using Gradient Mapping

Once installed, you can use the tool to grade your images by following these steps:

  1. Open your image in Paint.NET.
  2. Duplicate your base layer so you can adjust opacity and blend modes later.
  3. Navigate to the top menu and click Adjustments > Gradient Mapping.
  4. Use the interface to build your gradient:
    • The left side of the gradient bar represents the darkest areas (shadows).
    • The middle represents midtones.
    • The right side represents the brightest highlights.
  5. Click anywhere along the gradient spectrum to add color nodes, and choose your desired hues.
  6. Click OK to apply the effect.
  7. Open the Layer Properties (F4) of the graded layer and lower the opacity or change the blend mode to Overlay, Soft Light, or Color to blend the grading naturally with the original image.
