How to Save an Image as a TIFF in Paint.NET

Paint.NET provides built-in support for saving and exporting images in the Tagged Image File Format (TIFF), which is widely favored for high-quality printing, archiving, and uncompressed raster storage. This guide provides a direct, step-by-step walkthrough to help you save any image as a TIFF file in Paint.NET, including how to configure critical output settings such as bit depth and compression.

Step 1: Open Your Image

Launch Paint.NET and open the project or image you wish to save. If you are working on a new design, ensure all edits are finalized before exporting.

Step 2: Open the "Save As" Dialog

  1. Click on the File menu located in the top-left corner of the window.
  2. Select Save As... from the dropdown menu, or press the keyboard shortcut Ctrl + Shift + S.

Step 3: Select the TIFF Format

  1. In the file explorer window that appears, navigate to the folder where you want to store your file.
  2. Enter your desired file name in the File name field.
  3. Click the Save as type dropdown menu at the bottom of the window.
  4. Scroll through the list and select TIFF (.tif; .tiff).
  5. Click the Save button.

Step 4: Configure TIFF Settings

After clicking "Save," Paint.NET will display the Save Configuration dialog window. Adjust the following settings according to your needs:

  • Bit Depth:
    • Auto-detect: Automatically selects the best depth based on your image's colors and transparency.
    • 32-bit: Preserves full 24-bit color along with an 8-bit alpha (transparency) channel.
    • 24-bit: Standard full-color output without transparency.
    • 8-bit: Reduces the image to a 256-color palette to minimize file size.
  • Dithering: If you select an 8-bit depth, set the dither level to smooth color transitions.
  • Compression: Choose a compression algorithm to reduce file size without losing image data:
    • None: Saves the file without compression, resulting in the largest file size.
    • LZW: A standard lossless compression method supported by nearly all image viewers.
    • Deflate / ZIP: Highly efficient lossless compression that produces smaller files than LZW, though slightly less compatible with legacy software.

Step 5: Finalize the Export

Once your settings are configured, check the preview pane on the right side of the window to verify the estimated file size and image appearance. Click OK to process and save your TIFF image. If your image contains multiple layers, Paint.NET will automatically flatten them into a single layer to complete the TIFF export.
