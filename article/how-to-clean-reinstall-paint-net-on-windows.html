How to Clean Reinstall Paint.NET on Windows

When Paint.NET suffers from persistent crashes, startup errors, or failed updates, a standard uninstall often leaves behind corrupted configuration files and registry entries that cause the problem to return. This guide details how to perform a completely clean reinstallation of Paint.NET. Following these steps will remove all lingering cache files, configurations, and broken dependencies before installing a fresh, stable version of the software.

Step 1: Back Up Custom Plugins and Palettes

If you use custom effects, file-type plugins, or color palettes, back them up before purging the installation files:

  1. Press Windows Key + R to open the Run dialog box.
  2. Type %LOCALAPPDATA%\paint.net and press Enter. Copy any custom folders (such as Effects or Palettes) to your Desktop.
  3. Check C:\Program Files\paint.net for custom additions in the Effects or FileTypes directories and back them up as well.

Step 2: Uninstall Paint.NET

  1. Right-click the Start button and select Installed apps (or Apps & features on Windows 10).
  2. Locate Paint.NET in the list.
  3. Click the three dots (or select the app) and click Uninstall. Follow the on-screen prompts to complete the process.

Note: If the standard uninstaller fails or errors out, use the Microsoft Program Install and Uninstall troubleshooter to force the removal.

Step 3: Delete Leftover App Data and Installation Files

Residual files must be manually cleared to prevent them from carrying over into the new installation.

  1. Press Windows Key + R, type %LOCALAPPDATA%, and press Enter.
  2. Locate the paint.net folder, right-click it, and select Delete.
  3. Press Windows Key + R, type C:\Program Files, and press Enter.
  4. If a paint.net folder remains here, delete it.
  5. Navigate to your Documents folder and remove or rename the paint.net User Files directory if it exists.

Step 4: Remove Residual Registry Keys

Clear old registry values that may store corrupted window positions, tool states, or invalid plugin references:

  1. Press Windows Key + R, type regedit, and press Enter to open the Registry Editor.
  2. Navigate to: HKEY_CURRENT_USER\Software\paint.net
  3. Right-click the paint.net folder and select Delete.
  4. Navigate to: HKEY_LOCAL_MACHINE\SOFTWARE\paint.net (if present) and delete this folder as well.
  5. Close the Registry Editor.

Step 5: Restart Your Computer

Restart your system. This releases any locked system resources, unloads any remaining DLL handles from memory, and finalizes the registry cleanup.

Step 6: Download and Install a Fresh Copy

  1. Download the latest installer directly from the official Paint.NET website or through the Microsoft Store.
  2. If using the standalone installer, extract the .zip archive completely before running the setup executable.
  3. Run the installer and choose the Quick installation option to apply standard, stable configurations.

Step 7: Verify and Restore Custom Data

  1. Launch Paint.NET to ensure it opens and functions without errors.
  2. If you backed up plugins in Step 1, restore them gradually rather than all at once. An outdated or broken plugin is often the original cause of persistent crashes, so testing them individually ensures ongoing stability.
