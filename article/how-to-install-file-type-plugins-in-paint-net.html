How to Install FileType Plugins in Paint.NET

Paint.NET supports a wide variety of custom image formats through community-made FileType plugins, allowing you to open and save files such as PSD, SVG, and animated GIFs. This guide explains how to install these plugins by placing the required .dll files into the software's dedicated plugin directory. Whether you use the classic desktop installer or the Microsoft Store version of Paint.NET, following these steps will quickly expand your software's format compatibility.

Step 1: Download and Extract the Plugin

  1. Download the desired FileType plugin, usually distributed as a .zip file from the official Paint.NET forum.
  2. Right-click the downloaded .zip file and select Extract All to unpack its contents.
  3. Locate the file ending in .dll (and any associated .dll dependency files included in the download).

Step 2: Unblock the File (If Necessary)

Windows sometimes blocks .dll files downloaded from the internet for security reasons.

  1. Right-click the extracted .dll file and select Properties.
  2. Look at the bottom of the General tab for an Unblock checkbox next to the "Security" warning.
  3. Check the Unblock box and click Apply, then OK.

Step 3: Locate the Paint.NET FileTypes Folder

The target folder depends on how you installed Paint.NET:

  • For the Classic Installer version: Navigate to: C:\Program Files\paint.net\FileTypes (Note: If you installed the program in a custom location, look for the FileTypes subfolder inside your custom directory.)

  • For the Microsoft Store version: Navigate to your Documents folder: C:\Users\<YourUsername>\Documents\paint.net User Files\FileTypes (If the paint.net User Files or FileTypes folders do not exist, create them manually).

Step 4: Move the Plugin Files

  1. Copy the unblocked .dll file.
  2. Paste it directly into the FileTypes folder you located in Step 3.
  3. If prompted for administrator permissions, click Continue to grant access.

Step 5: Restart Paint.NET

Close Paint.NET if it is currently running, then launch it again. The software scans the FileTypes folder during startup. To verify the installation, click File > Open or File > Save As and check the dropdown menu for the newly installed file format.
