How to Make a Synthwave Grid in Paint.NET

Creating a retro 1980s synthwave landscape in Paint.NET is a straightforward process that relies on perspective transformation, vibrant neon color palettes, and layer blending modes. This guide walks you through setting up the dark retro aesthetic, generating a 3D-style perspective grid, building a glowing neon horizon, and adding the iconic striped synthwave sun using only native tools and basic Paint.NET features.

Step 1: Set Up the Canvas and Background

  1. Open Paint.NET and create a new image (a standard 1920x1080 canvas works best).
  2. Select the Paintbrush or Paint Bucket tool and fill the default "Background" layer with pure black (#000000).
  3. Add a new layer by clicking the Add New Layer icon in the Layers panel and name it "Sky Gradient."
  4. Select the Gradient tool (shortcut: G), set the primary color to deep purple (#1A0033) and the secondary color to pitch black (#000000).
  5. Drag the gradient from the bottom of the canvas to the top so the darkest shade sits at the top and the purple glow concentrates near the center.

Step 2: Draw the Flat 2D Grid

  1. Add a new layer and name it "Flat Grid."
  2. Choose a bright neon color, such as cyan (#00FFFF) or hot pink (#FF007F).
  3. Select the Line/Curve tool. Set the brush width to 2 or 3 pixels.
  4. Draw evenly spaced horizontal lines across the entire canvas using the Shift key to ensure straight lines.
  5. Draw evenly spaced vertical lines across the canvas, forming an evenly proportioned checkerboard pattern across the entire layer.

Step 3: Transform the Grid into 3D Perspective

  1. With the "Flat Grid" layer selected, go to the top menu and select Layers > Rotate / Zoom (or press Ctrl + Shift + Z).
  2. In the Rotate / Zoom dialog:
    • Adjust the Tilt angle (pitch) forward so the grid tilts backward toward the horizon.
    • Lower the Pan Y slider to move the tilted plane to the lower half of the canvas.
    • Increase the Zoom slider if necessary so the grid edges reach the bottom corners of the screen.
  3. Click OK.
  4. Use the Rectangle Select tool to select and delete any portion of the grid extending above the halfway line of your canvas, establishing a clean horizon.

Step 4: Add the Neon Glow Effect

  1. Duplicate the perspective grid layer by clicking the Duplicate Layer button.
  2. Select the lower grid layer and go to Effects > Blurs > Gaussian Blur.
  3. Set the blur radius between 10 and 20 to create a soft neon diffusion behind the crisp lines.
  4. Double-click the blurred layer in the Layers panel, set its Blend Mode to Additive, and increase the opacity if needed.
  5. Repeat this step with a smaller blur (3 to 5 pixels) on another duplicate layer to produce a multi-tiered neon glow.

Step 5: Construct the Iconic Retro Sun

  1. Create a new layer above the sky but behind the grid layers, and name it "Sun."
  2. Select the Ellipse Select tool, hold Shift to constrain proportions, and draw a large circle centered above the horizon line.
  3. Select the Gradient tool, choose bright yellow (#FFFF00) as the primary color and hot magenta (#FF007F) as the secondary color. Draw a linear gradient from top to bottom inside the selection.
  4. To add the retro horizontal cuts:
    • Select the Rectangle Select tool.
    • Draw thin horizontal rectangles across the lower half of the sun, making each gap progressively thicker toward the bottom.
    • Press Delete to clear the selected stripes, revealing the dark sky behind it.

Step 6: Final Horizon Blend and Atmosphere

  1. Add a new layer directly above the sun and grid layers, naming it "Horizon Glow."
  2. Select the Line/Curve tool with a white or pale pink primary color and a 3-pixel width. Draw a straight line directly across the horizon where the grid ends.
  3. Apply a Gaussian Blur of 15 to 25 to this line to create an intense light source at the vanishing point.
  4. Add another transparent layer, set the primary color to bright magenta or cyan, and use the Linear Gradient tool set to transparent mode to cast a subtle upward haze from the horizon line into the sky.
