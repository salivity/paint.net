Paint.NET Lasso Select Tool Shortcut

This guide explains the keyboard shortcut used to activate the Lasso Select tool in Paint.NET, how the tool selection cycle works, and how to use modifier keys to manage freehand selections efficiently. Mastering this shortcut helps streamline your image editing workflow by reducing the need to manually click through the Tools palette.

The Shortcut Key: S

In Paint.NET, the keyboard shortcut to access the Lasso Select tool is the letter S.

Because Paint.NET groups its selection tools under a single hotkey, pressing S cycles through all available selection utilities in the following order:

  1. Rectangle Select
  2. Lasso Select
  3. Ellipse Select
  4. Magic Wand

To activate the Lasso Select tool, press S repeatedly until the Lasso icon is highlighted in the Tools window. If a selection tool is already active, pressing S once or twice will switch directly to the Lasso Select tool.

Using the Lasso Select Tool

Once the Lasso Select tool is active, click and drag your cursor around the area you want to isolate. Releasing the mouse button automatically closes the selection loop by connecting the start and end points with a straight line.

Selection Modes and Modifiers

You can combine the Lasso Select tool with keyboard modifiers to adjust active selections:

  • Add (Union): Hold Ctrl while drawing to add a new area to your existing selection.
  • Subtract (Difference): Hold Alt while drawing to remove an area from your existing selection.
  • Invert: Hold Ctrl and right-click to invert the selection behavior.
  • Intersect: Hold both Ctrl and Alt simultaneously while drawing to keep only the overlapping portion of the selections.
  • Deselect: Press Ctrl + D to clear any active selection.
