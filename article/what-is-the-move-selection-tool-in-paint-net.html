What Is the Move Selection Tool in Paint.NET?

The Move Selection tool in Paint.NET allows users to reposition, resize, and rotate an active selection boundary without altering or moving the underlying image pixels. This guide covers the tool's core functions, how to use it, and how it differs from the standard Move Selected Pixels tool.

Primary Function

The Move Selection tool (represented by a white arrow icon in the Tools palette) manipulates only the selection outline—often visualized as "marching ants." When you create a selection using the Rectangle, Ellipse, Lasso, or Magic Wand tools, the Move Selection tool lets you adjust the exact area targeted by that selection without cutting, transforming, or copying the actual content inside.

Key Capabilities

  • Repositioning Boundaries: Clicking and dragging anywhere inside the active selection moves the boundary across the canvas. This is useful when you have created a precisely sized selection area and want to apply it to a different part of your image.
  • Resizing and Scaling: When the tool is active, control handles appear around the bounding box of the selection. Dragging these handles resizes the boundary horizontally, vertically, or proportionally.
  • Rotating Selections: Right-clicking and dragging anywhere on the canvas rotates the selection boundary around a central pivot point, allowing you to align selections with angled elements in an image.

Difference Between Move Selection and Move Selected Pixels

Paint.NET provides two arrow-based transformation tools, each serving a distinct purpose:

  • Move Selection (White Arrow): Modifies only the selection perimeter. The pixels underneath remain untouched.
  • Move Selected Pixels (Blue Arrow): Cuts the image data inside the selection and moves, scales, or rotates the actual pixels, leaving a transparent area behind on the active layer.

How to Use the Tool

  1. Create a selection using any selection tool (Rectangle, Ellipse, Lasso, or Magic Wand).
  2. Select the Move Selection tool from the Tools window, or press the shortcut key M until the white arrow is active.
  3. Left-click and drag inside the selection to change its position, drag the corner or edge handles to scale it, or right-click and drag to rotate it.
