How to Open Canvas Size in Paint.NET with a Shortcut

This article provides a direct guide on how to open the Canvas Size dialog in Paint.NET using a quick keyboard shortcut. You will learn the exact key combination required, the difference between resizing the canvas versus resizing an image, and how to configure the canvas settings once the dialog window appears.

The Canvas Size Keyboard Shortcut

To open the Canvas Size dialog in Paint.NET immediately, press:

Ctrl + Shift + R

Press and hold the Ctrl and Shift keys together, tap the R key, and then release all three keys. The Canvas Size window will instantly pop up over your active workspace.

How to Use the Canvas Size Dialog

Once the dialog box is open, you can adjust your project's workspace dimensions without scaling the actual artwork:

  1. Choose Sizing Method: Select whether to resize by Percentage or by absolute Absolute size (pixels, inches, or centimeters).
  2. Enter Dimensions: Type your desired Width and Height. Check the Maintain aspect ratio box if you want the height and width to scale proportionally.
  3. Select Anchor Point: Use the Anchor grid to determine where your current artwork remains positioned relative to the new canvas boundaries. Selecting the center keeps your work centered, while selecting a corner expands or crops the canvas from that specific side.
  4. Apply Changes: Click OK or press Enter on your keyboard to apply the new dimensions.

Canvas Size vs. Resize Shortcut

Paint.NET provides two distinct features for altering project dimensions. It is important not to confuse their shortcuts:

  • Canvas Size (Ctrl + Shift + R): Expands or crops the background working area. The existing pixels and drawn elements stay their original size.
  • Resize (Ctrl + R): Scales, stretches, or shrinks the existing image and its contents up or down.
