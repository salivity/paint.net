Where to Put Paint.NET Plugin DLL Files

This guide explains the correct folder destinations for Paint.NET DLL plugin files, covering both standard and Microsoft Store installations. Depending on whether your plugin introduces a new visual effect or adds support for an alternative file format, it must be placed into a specific directory so the application can load it properly.

Determining the Plugin Type

Paint.NET categorizes plugins into two main types:

  • Effect Plugins: DLLs that add filters, adjustments, or drawing tools. These belong in an Effects folder.
  • File Type Plugins: DLLs that allow Paint.NET to open or save custom image formats (such as WebP, DDS, or PSD). These belong in a FileTypes folder.

Standard Installation (Classic Installer)

If you installed Paint.NET using the standard installer downloaded from the official website, navigate to the main application directory located in your Program Files:

  • For Effect Plugins:
    C:\Program Files\paint.net\Effects
  • For File Type Plugins:
    C:\Program Files\paint.net\FileTypes

Note: Modifying contents inside C:\Program Files requires administrative privileges.

Microsoft Store and User-Specific Installation

If you purchased Paint.NET from the Microsoft Store, or if you do not have administrative rights on your machine, you cannot modify the installation folder directly. Instead, place your DLL files in your personal user directory:

  • For Effect Plugins:
    Documents\paint.net User Files\Effects
  • For File Type Plugins:
    Documents\paint.net User Files\FileTypes

If these subfolders do not already exist inside the Documents\paint.net User Files directory, you can safely create them manually. This user-level path works on both the Microsoft Store edition and classic desktop installations.

How to Install the DLL Files

  1. Close Paint.NET: Ensure the program is not currently running.
  2. Extract the Files: If the plugin downloaded as a .zip archive, extract it to access the .dll file.
  3. Unblock the File (If Necessary): Right-click the .dll file, select Properties, check the Unblock box at the bottom of the General tab if present, and click OK. Windows often blocks DLLs downloaded from the internet.
  4. Move the File: Copy and paste the .dll into either the Effects or FileTypes folder based on its function and your installation type.
  5. Relaunch Paint.NET: Start the application. Effect plugins will appear under the Effects or Adjustments menus, while file type plugins will be visible in the Open and Save As format dropdown menus.
