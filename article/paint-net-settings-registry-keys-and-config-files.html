Paint.NET Settings Registry Keys and Config Files

Paint.NET stores its user preferences, tool configurations, and interface states primarily within the Windows Registry for standard installations, while utilizing specific user directories for auxiliary assets like custom palettes and shapes. Depending on whether you use the standard installer or the Microsoft Store package, the location of these settings shifts between direct registry entries and virtualized container storage.

The Primary Registry Key (Standard Classic Installer)

For standard installations downloaded via the installer or MSI, Paint.NET saves nearly all operational user preferences to the Windows Registry under the current user's profile:

  • Registry Path: HKEY_CURRENT_USER\Software\Paint.NET

Inside this key, Paint.NET stores specific string, DWORD, and binary values controlling:

  • Tool Configuration: Default and last-used brush widths, tolerance levels, selection modes, and antialiasing toggles.
  • UI Layout: Window positions, panel visibility (Tools, History, Layers, Colors), and docking coordinates.
  • Canvas Defaults: Default canvas dimensions, measurement units (pixels, inches, centimeters), and resolution settings.
  • Application Settings: Update check intervals, hardware acceleration (GPU rendering) toggles, and recent color choices.

Microsoft Store / MSIX Package Registry Location

If Paint.NET was installed through the Microsoft Store or deployed as an MSIX/AppX package, Windows isolates its registry writes through container virtualization.

Instead of directly altering your primary registry, changes are redirected to a private hive located at:

  • File Path: %LOCALAPPDATA%\Packages\dotPDNLLC.paint.net_[PackageID]\SystemAppData\Helium\User.dat

When opened in an elevated context using a registry editor, this virtualized hive maps internally to the same Software\Paint.NET path structure.

Configuration Files and Asset Folders

While runtime preferences reside in the registry, specific user-generated settings and custom assets are stored in configuration directories within your Windows user profile:

  • Palettes and Custom Shapes:
    • Path: %USERPROFILE%\Documents\Paint.NET User Files\
    • Subfolders: \Palettes\ (contains custom .txt color palette files) and \Shapes\ (contains custom vector .xaml or .shape files).
  • Application Caches and Logs:
    • Path: %LOCALAPPDATA%\paint.net\
    • Contains crash logs, temporary update staging files, and plugin cache data.

Backing Up and Resetting Preferences

To back up settings from a classic installation, open the Command Prompt and export the key:

reg export "HKEY_CURRENT_USER\Software\Paint.NET" "%USERPROFILE%\Desktop\PaintNET_Settings.reg"

To reset Paint.NET to its factory default settings, close the application and delete the HKEY_CURRENT_USER\Software\Paint.NET key. Paint.NET will recreate the registry tree with default values the next time it launches.
