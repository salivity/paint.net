How to Export an Image as BMP in Paint.NET

This guide explains how to export any image or project as a Bitmap (.bmp) file using Paint.NET. The process involves opening your file, selecting the correct file format in the save dialog, configuring the appropriate bit-depth settings, and confirming layer flattening so the image can be read by any application supporting the Windows Bitmap format.

Step 1: Open Your Image

Launch Paint.NET and open the project or image file you wish to convert by going to File > Open or pressing Ctrl + O.

Step 2: Open the Save As Menu

Navigate to the top menu bar, click on File, and select Save As... from the dropdown menu. Alternatively, press the keyboard shortcut Ctrl + Shift + S.

Step 3: Select the BMP File Type

In the file explorer window that appears:

  1. Choose the destination folder where you want to store the output file.
  2. Enter your desired file name in the File name field.
  3. Click the Save as type dropdown menu and select **BMP (*.bmp)**.
  4. Click Save.

Step 4: Configure Bit Depth Settings

After clicking Save, the Save Configuration dialog box will appear. Here, you can specify the color depth for your Bitmap file:

  • Auto-detect: Paint.NET will automatically choose the most efficient bit depth based on your image's colors.
  • 24-bit: Standard True Color format (8 bits per channel for Red, Green, and Blue), ideal for general use and compatibility.
  • 32-bit: True Color with an Alpha (transparency) channel.
  • 8-bit or lower: Uses an indexed color palette, resulting in smaller file sizes but reduced color fidelity.

Select your preferred configuration and click OK.

Step 5: Flatten Layers (If Prompted)

The BMP format does not support multiple layers. If your project contains more than one layer, Paint.NET will display a prompt asking to flatten the image. Click Flatten to merge all visible layers into a single background layer and finalize the export.
