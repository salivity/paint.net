How to Clear Paint.NET Temporary Cache Files

Paint.NET creates temporary scratch files to store history states, undo actions, and canvas layers while you work on an image. While the application typically removes these files upon a normal exit, unexpected crashes or prolonged use can leave gigabytes of orphaned data behind on your hard drive. This guide provides straightforward methods to safely locate and remove these leftover Paint.NET cache files to reclaim disk space without affecting your saved projects or software stability.

Step 1: Fully Close Paint.NET

Before deleting any temporary files, make sure Paint.NET is not running. If the application is open, it actively locks its temporary cache files, and attempting to delete them can cause software errors or data corruption in unsaved work.

  1. Save any open projects.
  2. Close Paint.NET.
  3. Open the Task Manager (Ctrl + Shift + Esc) and ensure no background instances of paintdotnet.exe are still active.

Step 2: Delete Files from the Windows Temp Folder

Paint.NET stores its working swap files directly in the primary Windows temporary directory.

  1. Press Windows Key + R to open the Run dialog box.
  2. Type %temp% and press Enter. This opens the folder located at C:\Users\[Username]\AppData\Local\Temp.
  3. Locate the Paint.NET files:
    • Look for files with names starting with pdn (for example, files named pdn_scratch_... or similar temporary swap files).
    • Look for any folders labeled Paint.NET.
  4. Select these specific files and press Delete (or Shift + Delete to remove them permanently).
  5. If Windows displays a message stating that a file is in use, skip that file, as it may be tied to another active system process.

Step 3: Clear the Paint.NET Crash Log Directory (Optional)

If Paint.NET experiences crashes, it generates crash log text files that persist over time.

  1. In the same %temp% folder, look for a subfolder named PaintDotNet.
  2. Inside, you may find folders like CrashLogs.
  3. Open this folder and safely delete any text files containing crash reports to free up minor space.

Step 4: Use Windows Disk Cleanup

If you prefer an automated approach that handles all system temp data safely:

  1. Press Windows Key + S, search for Disk Cleanup, and launch the utility.
  2. Select your main drive (usually C:) and click OK.
  3. Check the box for Temporary files.
  4. Click OK, then select Delete Files to confirm.

This process clears the default temporary file location, safely sweeping away unneeded Paint.NET cache data alongside general system clutter.
