Paint.NET Image Resize Keyboard Shortcut

This article explains how to quickly access the Image Resize dialog in Paint.NET using a built-in keyboard shortcut. Mastering this hotkey allows you to adjust the resolution, dimensions, and scaling of your images efficiently without navigating through multiple dropdown menus.

The keyboard shortcut to open the Image Resize dialog in Paint.NET is Ctrl + R.

When you press Ctrl + R on your keyboard while an image is open, the "Resize" window will immediately appear on your screen. From this menu, you can modify several image parameters:

  • By absolute size: Change the exact width and height of the image in pixels, inches, or centimeters.
  • By percentage: Scale the entire image up or down proportionally relative to its original size.
  • Maintain aspect ratio: Keep the width and height linked to prevent the image from stretching or distorting.
  • Resampling: Choose the interpolation algorithm (such as Best Quality, Bicubic, Bilinear, or Nearest Neighbor) used to redraw the pixels.

If you prefer using the mouse, you can access the same window by clicking Image in the top menu bar and selecting Resize.

Note that resizing the image changes the dimensions of the artwork itself. If you want to change the size of the working area without stretching or shrinking the artwork, use the Canvas Size shortcut instead, which is Ctrl + Shift + R.
