How to Backup Paint.NET Plugins Before Updating

Updating Paint.NET ensures you have the latest features, security patches, and performance improvements, but major updates can occasionally displace or overwrite your custom third-party tools. Backing up your custom plugin collection before running an update protects your workflow and allows you to quickly restore your favorite effects and file type handlers. This guide covers how to locate your Paint.NET plugin folders, safely copy your files to a secure backup directory, and restore them if necessary after the update completes.

Step 1: Locate Your Plugin Directories

Paint.NET stores plugins in specific directories depending on your installation method (Standard Classic Installer or the Microsoft Store version). Check both possible locations to ensure you capture every installed tool.

  • Classic Installation Directory: Open File Explorer and navigate to: C:\Program Files\paint.net Inside this folder, you will find two primary directories containing your plugins:
    • Effects (contains custom tools, filters, and adjustments)
    • FileTypes (contains handlers for custom image formats)
  • User App Data / Documents Directory: Modern versions of Paint.NET also support user-level plugin installations, which is standard for Microsoft Store users. Navigate to: Documents\paint.net App Files Look for the corresponding Effects and FileTypes folders inside.

Step 2: Create a Backup Folder

  1. Right-click an empty space on your Desktop, an external drive, or within a cloud storage folder.
  2. Select New > Folder.
  3. Name the folder something identifiable, such as Paint.NET Plugin Backup [Current Date].
  4. Inside this new folder, create two subfolders named Effects and FileTypes to mirror the original structure.

Step 3: Copy Your Plugin Files

  1. Open the original Effects folder identified in Step 1.
  2. Select all files (typically .dll files) and any associated configuration files or subfolders.
  3. Copy them (Ctrl + C) and paste them (Ctrl + V) into your newly created Effects backup folder.
  4. Repeat the exact same process for the FileTypes directory.

Step 4: Run the Paint.NET Update

Once your files are copied to the backup folder, proceed with updating Paint.NET.

  1. Open Paint.NET.
  2. Click the Gear icon in the top-right corner to open Settings.
  3. Go to the Updates tab and select Check Now.
  4. Follow the on-screen prompts to download and install the update, then restart the application.

Step 5: Verify and Restore

After the update finishes, open Paint.NET and check the Effects and Adjustments menus to confirm that your custom plugins are still present and functional.

If any plugins are missing:

  1. Close Paint.NET completely.
  2. Copy the missing .dll files from your backup folder.
  3. Paste them back into the active Effects or FileTypes directory.
  4. Relaunch Paint.NET.

Note: If an older plugin fails to load or causes an error after an update, it may be incompatible with the new version. In that case, check the official Paint.NET forums to download an updated release of that specific plugin.
