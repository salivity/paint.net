Finding Third-Party Effect Plugins in Paint.NET

Third-party effect plugins expand Paint.NET’s capabilities by seamlessly integrating into its existing menu structure. This article explains how installed plugins are processed, the specific menus and submenus where they appear, how plugin developers control their placement, and how to identify custom tools alongside the software's native features.

Primary Menu Locations

Once a third-party plugin file (typically a .dll file) is placed into the Paint.NET Effects directory and the application is launched, the software automatically registers the tool. Depending on how the plugin is categorized by its developer, it will appear in one of two main top-level menus:

  • The Effects Menu: The vast majority of third-party plugins reside under the Effects menu at the top of the interface. This includes filters, stylization tools, noise generators, artistic modifiers, and procedural renderers.
  • The Adjustments Menu: If a developer codes a plugin specifically as a color or tone adjustment rather than a spatial effect, it will appear under the Adjustments menu alongside native tools like Brightness/Contrast, Curves, and Hue/Saturation.

Submenu Categorization

Paint.NET does not group third-party plugins into an "External" or "Plugins" section. Instead, they are sorted into submenus based on instructions embedded within the compiled plugin code.

Standard Submenus

Developers often target Paint.NET's native submenus to keep the interface uniform. Third-party tools will populate directly into these built-in categories:

  • Artistic (e.g., oil painting, sketches)
  • Blurs (e.g., motion blurs, radial blurs)
  • Distort (e.g., ripples, twirls, perspective shifts)
  • Noise (e.g., noise reduction, grain generation)
  • Photo (e.g., sharpening, red-eye removal, glow)
  • Render (e.g., clouds, grids, fractals)
  • Stylize (e.g., edge detection, embossing)

Custom and Author-Specific Submenus

If a developer chooses a non-standard category name, Paint.NET automatically generates a new submenu under Effects. Common examples include plugin packs named after their creators (such as "BoltBait" or "Kris Vandermotten") or specialized function sets (such as "Object," "Color," or "Selection").

Root Menu Placement

If a developer does not define a submenu category in their code, the effect will appear loose at the bottom of the main Effects drop-down list, below the categorized submenus.

Visual Identification and Sorting

Third-party plugins are organized alphabetically within their respective submenus alongside native tools.

To help distinguish individual tools, developers typically embed a custom 16x16-pixel icon into the plugin, which displays immediately to the left of the effect name in the menu. Selecting the menu item opens the plugin's configuration window, allowing parameters to be adjusted before applying the effect to the canvas or active selection.
