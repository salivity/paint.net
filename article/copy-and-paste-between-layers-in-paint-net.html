Copy and Paste Between Layers in Paint.NET

Copying content from one layer and pasting it onto another in Paint.NET transfers the selected pixels from your source layer directly into the active target layer as an active, floating selection. This allows you to position, resize, or adjust the copied elements before permanently committing them to the target layer's existing pixel data.

When you select an area on a source layer and copy it (Ctrl + C), Paint.NET saves the pixel information along with its transparency (alpha channel) to your clipboard. Switching to a different layer in the Layers window designates that layer as the active target for subsequent actions.

When you paste (Ctrl + V) onto the target layer, Paint.NET does not automatically create a new layer. Instead, the copied pixels are introduced as a floating selection directly on top of the active layer. Paint.NET automatically switches to the Move Selected Pixels tool, displaying a bounding box with control handles around the pasted content.

While the selection remains active, the original pixels on the target layer underneath it remain unchanged. You can freely translate, scale, or rotate the floating selection. If the source and target exist on canvases of the exact same dimensions, Paint.NET pastes the content in the exact X and Y coordinates from which it was copied.

The paste operation becomes permanent once the selection is committed. You commit the pixels by pressing Enter, pressing Ctrl + D to deselect, or by clicking anywhere outside the selection boundary with an active selection tool. Once committed, the pasted pixels permanently overwrite and replace any existing pixel data on that specific layer beneath them.

If you instead want the copied content isolated from the target layer's existing artwork, you must use Paste into New Layer (Ctrl + Shift + V), which generates a completely independent layer above the currently active one.
