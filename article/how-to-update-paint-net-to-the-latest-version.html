How to Update Paint.NET to the Latest Version

Keeping Paint.NET up to date ensures you have access to the latest editing tools, performance improvements, and security patches. This guide covers the quickest methods to update Paint.NET to its latest release, including the built-in updater for the standard classic version, the update process for the Microsoft Store edition, and manual reinstallation.

Method 1: Using the Built-In Updater (Classic Version)

If you installed Paint.NET using the standard installer from the official website, you can update directly through the program interface.

  1. Open Paint.NET.
  2. Click the Gear icon (Settings) located in the upper-right corner of the window. Alternatively, click Help in the top menu bar and select Check for Updates.
  3. In the Settings window, select the Updates tab from the left sidebar.
  4. Click the Check Now button.
  5. If an update is available, click Install.
  6. Paint.NET will download the update package. Once downloaded, close the application when prompted so the installer can complete the process.
  7. Restart Paint.NET once the installation finishes.

Method 2: Updating via the Microsoft Store

If you purchased or installed the application through the Microsoft Store, updates are handled through Windows rather than the app itself.

  1. Open the Microsoft Store application on your PC.
  2. Click on the Library icon located at the bottom-left corner of the window.
  3. Click the Get updates button near the top right.
  4. If a new version of Paint.NET is available, it will automatically download and install.

Method 3: Manual Update

If the internal updater fails or you are encountering errors, you can manually apply the update.

  1. Download the latest installer directly from the official Paint.NET website.
  2. Close any running instances of Paint.NET.
  3. Extract the downloaded zip file and run the installer executable.
  4. Select Express installation and proceed through the prompts. The installer will automatically overwrite your previous version while preserving your existing user settings and compatible plugins.
