How to Save JPEG and Adjust Quality in Paint.NET

Saving an image as a JPEG in Paint.NET allows you to reduce file size while balancing visual fidelity. This guide walks you through the step-by-step process of exporting your canvas to the JPEG format, accessing the save configuration dialog, and utilizing the quality slider to dial in the exact compression level you need.

Step 1: Open the Save As Menu

Once you finish editing your image, click on File in the top navigation bar and select Save As... from the dropdown menu. Alternatively, press Ctrl + Shift + S on your keyboard to open the save window immediately.

Step 2: Set File Format to JPEG

In the file explorer window:

  1. Choose the destination folder on your computer where you want to store the file.
  2. Enter your desired file name in the File name field.
  3. Click the Save as type dropdown menu and select JPEG (.jpg, .jpeg, .jpe, .jfif).
  4. Click Save.

(Note: If your project contains multiple layers, Paint.NET will prompt you to flatten the image, as the JPEG format does not support layers. Click Flatten to proceed.)

Step 3: Adjust the Quality Compression Slider

After clicking Save, the Save Configuration dialog box will appear on your screen. This window allows you to customize your export settings before the final file is written to your drive.

  1. Locate the Quality slider on the left side of the dialog box.
  2. Drag the slider to the left to increase compression (reducing file size while lowering visual quality) or to the right to decrease compression (increasing visual quality while expanding file size). The value ranges from 0 (lowest quality, highest compression) to 100 (highest quality, lowest compression). A setting between 85 and 95 typically offers the best balance for everyday use.
  3. Observe the right-hand panel, which displays a real-time preview of the compressed image along with the estimated final file size in the bottom-right corner.
  4. Once you achieve the desired balance between appearance and file size, click OK to complete the export.
