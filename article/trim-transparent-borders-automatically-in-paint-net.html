Trim Transparent Borders Automatically in Paint.NET

Trimming transparent borders from images in Paint.NET ensures your graphics are neatly cropped around the subject without unnecessary empty space. While Paint.NET does not include a single-click "auto-trim during export" toggle, you can achieve this exact result instantly using native keyboard shortcuts or through an automated trimming plugin before saving your file as a transparent PNG.

Method 1: The Fast Native Shortcut (No Plugins Needed)

You can automatically detect the edges of your non-transparent content and crop it in seconds using built-in tools.

  1. Open your image in Paint.NET.
  2. Select the Magic Wand tool from the toolbar (keyboard shortcut: S until selected).
  3. In the top settings bar, set the Tolerance slider to 0% and ensure the Flood Mode is set to Contiguous.
  4. Click anywhere inside the transparent border area around your image.
  5. Invert the selection by pressing Ctrl + I. Paint.NET will now tightly outline only the visible, non-transparent pixels.
  6. Crop the canvas to the selected boundary by pressing Ctrl + Shift + X (or go to Image > Crop to Selection).
  7. Save the cropped file by pressing Ctrl + Shift + S, selecting PNG as the file type to preserve transparency, and clicking Save.

Method 2: Automating with the BoltBait Plugin Pack

For a one-click automatic trim without manual selections, you can use the community-standard BoltBait plugin pack.

  1. Download and install BoltBait's Plugin Pack into your Paint.NET Effects folder.
  2. Open your transparent image in Paint.NET.
  3. Navigate to Effects > Selection > Auto-Crop (or Trim).
  4. The plugin will instantly analyze the canvas, detect the non-transparent pixel boundary, and crop the canvas accordingly.
  5. Press Ctrl + Shift + S to export your trimmed graphic as a PNG.
