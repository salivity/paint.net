Paint.NET Native File Extension for Layers

Paint.NET uses the PDN (.pdn) file extension as its native format for preserving multi-layered image projects. This article explains what the PDN format is, why it is necessary for maintaining an editable project workflow, and how it differs from standard flattened image formats like PNG and JPEG.

The PDN File Format Explained

The proprietary and default file format for Paint.NET is PDN, which stands for "Paint.NET Document." When you save your work with the .pdn extension, the application stores the complete structure of your canvas. This includes:

  • Individual Layers: Every distinct layer remains intact, allowing you to edit, reorder, or delete specific visual elements at any time.
  • Layer Properties: Settings such as layer visibility, opacity, and blend modes (e.g., Multiply, Overlay, Add) are fully retained.
  • Transparency: Alpha channels for each layer are stored without alteration.

PDN vs. Standard Image Formats

Common image formats like JPEG, PNG, BMP, and GIF are designed for sharing, web display, and broad compatibility. However, these standard formats automatically flatten your canvas into a single base layer during the export process. Once an image is flattened and closed, the individual elements cannot be separated or modified independently.

Saving as a .pdn file ensures a non-destructive workflow. It allows you to pause a project, close the program, and return later with your entire working setup completely preserved.

Best Practices for Saving in Paint.NET

  1. Save Working Files as PDN: Always save your initial work as a .pdn file to maintain a master backup with all layers accessible.
  2. Export for Distribution: Once the design is finalized, use the "Save As" function to export a copy into a widely supported format:
    • PNG: For digital graphics requiring lossless compression and transparency.
    • JPEG: For photographs and complex images where smaller file sizes are required.
    • WebP: For modern, optimized web use.

Because the PDN format is native to Paint.NET, it cannot typically be opened by default image viewers or other graphic editors without specialized third-party plugins. Therefore, keeping both the master .pdn file and an exported delivery format is the recommended approach for any project.
