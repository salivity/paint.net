Maximum Brush Size in Paint.NET

This article explains the maximum brush width limits in Paint.NET's standard Brush tool. It covers the difference between the interface's preset dropdown values and the absolute maximum size you can manually enter, as well as how to adjust your brush to reach this maximum dimension.

In Paint.NET, the absolute maximum brush width you can set for the standard Brush tool is 2,000 pixels.

While the brush width dropdown menu in the top toolbar only lists preset sizes up to 500 pixels, you are not restricted to these choices. You can set a larger size by clicking inside the brush width input box, typing any value up to 2,000, and pressing Enter.

If you attempt to type a value greater than 2,000 pixels, Paint.NET will automatically clamp the value back down to the 2,000-pixel maximum limit.

You can also adjust the brush size dynamically using keyboard shortcuts. Pressing the right bracket key (]) increases the brush size, while the left bracket key ([) decreases it. Holding down either key will rapidly scale the brush size, stopping automatically once it reaches the 2,000-pixel ceiling.
