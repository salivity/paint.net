How to Export ICO Files in Paint.NET

Paint.NET does not natively support the .ICO format out of the box, but you can easily export custom icons by installing a free file-type plugin. This guide walks you through installing the required plugin, setting up your image dimensions, and saving your finished design as a standard Windows icon file.

Step 1: Install the Icon Format Plugin

  1. Close Paint.NET if it is currently running.
  2. Download the IcoCur (Icon, Cursor, and Animated Cursor) plugin for Paint.NET.
  3. Open the downloaded .zip archive and locate the IcoCur.dll file.
  4. Navigate to your Paint.NET installation directory, typically located at: C:\Program Files\paint.net\FileTypes (If you use the Windows Store version, place the file in Documents\paint.net App Files\FileTypes instead).
  5. Paste IcoCur.dll into the FileTypes folder. You may need to provide administrator permission to complete this step.

Step 2: Prepare Your Icon Canvas

  1. Launch Paint.NET.
  2. Go to File > New to create a new canvas.
  3. Set the image to a square aspect ratio. Standard Windows icon dimensions include 16x16, 32x32, 48x48, and 256x256 pixels. A 256x256 pixel canvas is recommended for modern, high-resolution displays.
  4. Ensure your background is transparent if you do not want a solid background surrounding your icon graphic.
  5. Create your design or paste an existing graphic onto the canvas.

(Optional: To create a multi-resolution icon containing multiple sizes within a single .ico file, create each size on a separate layer, scaling down your artwork accordingly).

Step 3: Save as an Icon File

  1. Click File > Save As... from the top menu.
  2. Enter a name for your file.
  3. In the Save as type drop-down menu, select **Icons (*.ico)**.
  4. Choose your destination folder and click Save.
  5. An icon configuration dialog will appear. Select your desired color depth (typically 32-bit for transparency support) and click OK to generate the .ico file.
