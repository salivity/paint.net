How to Ensure Correct Color Profiles in Paint.NET

Color shifts between editing and exporting in Paint.NET typically occur because the application fundamentally operates within the standard sRGB color space while handling external color profiles through specific metadata rules. This guide explains how color profiles function in Paint.NET, how to preserve embedded International Color Consortium (ICC) profiles during export, and the exact steps to guarantee that your exported images render consistently across different browsers, image viewers, and operating systems.

1. Update to the Latest Version of Paint.NET

Color management changed significantly starting with Paint.NET version 5.0. Earlier versions stripped or ignored color profiles entirely, frequently causing desaturated or overly saturated exports. Ensure you are running Paint.NET 5.0 or later, as modern versions utilize Windows Imaging Component (WIC) and Direct2D to preserve color profile metadata during file operations.

2. Work Within the sRGB Color Space

Paint.NET does not offer advanced soft-proofing or custom working spaces like Adobe RGB or ProPhoto RGB. It renders and composites all layers using the standard sRGB color space.

  • If you import an image with a wide gamut (such as Display P3 or Adobe RGB), convert the image to sRGB in an external utility or color-managed viewer before importing, or be aware that Paint.NET will map colors to sRGB.
  • Working with native sRGB source files prevents unexpected clipping of high-saturation tones when saving.

3. Choose a File Format That Supports Color Profiles

Not all file formats support embedded ICC profiles. When saving your work, select a format capable of retaining color metadata:

  • Supported formats: JPEG, PNG, TIFF, WebP, and AVIF.
  • Unsupported formats: BMP and standard 8-bit GIF (which will discard all ICC data and rely entirely on the viewer's default interpretation).

4. Enable Metadata Preservation on Save

Paint.NET stores ICC color profiles inside the image's metadata chunk. Disabling metadata during the export process strips the color profile and forces viewing software to guess the color space.

  1. Go to File > Save As...
  2. Choose your destination, name the file, and select a supported format (such as PNG or JPEG). Click Save.
  3. In the format settings configuration dialog that appears:
    • Look for the Save metadata or Include metadata option.
    • Ensure this checkbox is checked. If this option is unchecked to reduce file size, the embedded ICC profile is permanently deleted from the export.
  4. Click OK to complete the export.

5. Verify the Export in a Color-Managed Viewer

Operating system defaults can lead to false assumptions about color accuracy. Windows Photos, legacy Windows Photo Viewer, and modern web browsers handle untagged images differently:

  • Open the exported file in a color-managed web browser (such as Google Chrome, Mozilla Firefox, or Microsoft Edge).
  • Compare the exported image side-by-side with your Paint.NET canvas.
  • If the image appears identical in the browser to how it looked inside Paint.NET, the color rendering pipeline is correctly established.
