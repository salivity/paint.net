How to Subtract from a Selection in Paint.NET

This guide explains how to subtract portions from an active selection in Paint.NET. By utilizing the built-in Selection Mode options in the top toolbar or using quick mouse shortcuts, you can carve away unwanted areas from an existing selection to create precise, complex shapes for your image editing projects.

Method 1: Using the Selection Mode in the Toolbar

  1. Create an Initial Selection: Choose any selection tool from the Tools palette (such as the Rectangle Select, Lasso Select, Ellipse Select, or Magic Wand) and make your primary selection on the canvas.
  2. Locate the Selection Mode Setting: Look at the top toolbar above your canvas. By default, the Selection mode is set to Replace (represented by a solid blue square icon).
  3. Change the Mode to Subtract: Click the Selection mode dropdown menu and select Subtract (represented by an icon showing one square cutting into another with a minus symbol).
  4. Remove the Desired Area: Click and drag over the portion of the active selection you want to remove. Once you release the mouse, the overlapping area will be cut away from your selection.
  5. Reset the Mode: When finished, switch the mode back to Replace so future selections function normally.

Method 2: Using the Right-Click Shortcut (Fastest Method)

Paint.NET provides a built-in mouse shortcut that temporarily activates the subtract mode without requiring you to change settings on the toolbar.

  1. Create your initial selection with any selection tool.
  2. Select the tool you want to use to remove area (you can keep the same tool or switch to another, such as switching from the Rectangle Select to the Lasso Select).
  3. Right-click and drag across the area you want to eliminate.
  4. Release the right mouse button. The selected shape will immediately be subtracted from the existing selection.

Combining Different Selection Tools

You are not restricted to subtracting with the tool that created the initial boundary. For example, you can create a broad area with the Rectangle Select tool, switch to the Magic Wand or Lasso Select tool, set the mode to Subtract (or right-click), and carve out specific colors or freeform shapes from within that rectangle.
