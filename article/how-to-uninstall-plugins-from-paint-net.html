How to Uninstall Plugins from Paint.NET

Uninstalling an unwanted plugin from Paint.NET requires manually removing its associated file from your system, as the program does not feature a built-in plugin manager. This guide explains how to locate the correct directory for your installation type, identify the plugin file, and safely remove it to restore Paint.NET to its previous state.

Step 1: Close Paint.NET

Before modifying any application files, ensure Paint.NET is completely closed. If the program is running, Windows will lock the plugin files, preventing you from deleting or moving them.

Step 2: Open the Plugin Directory

The location of your plugins depends on whether you installed the classic desktop version or the Microsoft Store version.

For the Standard (Classic) Version:

  1. Open File Explorer.
  2. Navigate to: C:\Program Files\paint.net
  3. Open the Effects folder (for visual filters and tools) or the FileTypes folder (for custom file format support).

Note: In newer versions, user-installed plugins might also be located in your user profile at: Documents\paint.net User Files\Effects or Documents\paint.net User Files\FileTypes.

For the Microsoft Store Version:

  1. Open File Explorer.
  2. Navigate to your Documents folder: C:\Users\<YourUsername>\Documents\paint.net User Files
  3. Open either the Effects or FileTypes folder.

Step 3: Locate and Delete the Plugin File

  1. Browse through the folder to find the file associated with the unwanted plugin. Plugins generally use the .dll file extension.
  2. If you are unsure of the file name, check the original ZIP archive you downloaded, or look for a .dll that closely matches the name displayed in Paint.NET's menus.
  3. Select the .dll file (along with any associated .pdb or documentation files from the same plugin).
  4. Press Delete or right-click the file and select Delete.
    • Tip: If you might want the plugin back later, cut and paste the file into a backup folder outside of the Paint.NET directory instead of deleting it permanently.

Step 4: Verify the Removal

  1. Launch Paint.NET.
  2. Check the relevant menu (such as Effects or File > Open) to confirm the plugin is no longer visible. If it is gone, the uninstallation was successful.
