Using Ctrl with Color Picker in Paint.NET

In Paint.NET, holding the Ctrl key while clicking with the Color Picker tool temporarily reverses the tool's configured "After click" behavior. Depending on your current tool settings, this action either immediately returns you to your previously selected editing tool or keeps the Color Picker active so you can continue sampling colors.

The "After Click" Setting

The Color Picker features two operational modes accessible in the top toolbar under the "After click" dropdown menu:

  1. Do not switch tool: The Color Picker remains active after sampling a color.
  2. Switch to previous tool: Paint.NET samples the color and instantly switches back to whichever tool you were using before selecting the Color Picker.

How Ctrl Changes the Behavior

Holding the Ctrl key acts as a modifier that temporarily inverts whichever "After click" mode is currently active:

  • When set to "Do not switch tool": Holding Ctrl while clicking samples the pixel and automatically switches back to your previously active tool (such as the Paintbrush, Pencil, or Eraser). This allows you to quickly grab a color and resume drawing without manually selecting your prior tool.
  • When set to "Switch to previous tool": Holding Ctrl while clicking bypasses the automatic tool switch. This keeps the Color Picker selected, allowing you to sample multiple colors in succession across your canvas without being forced back to your drawing tool after the first click.

Primary vs. Secondary Color Selection

This shortcut functions with both mouse buttons:

  • Ctrl + Left-Click: Samples the target pixel to your Primary color palette while inverting the tool switch behavior.
  • Ctrl + Right-Click: Samples the target pixel to your Secondary color palette while inverting the tool switch behavior.
