Paint.NET Magic Wand: Global vs Local Flood Mode

This article explains the core differences between the Global and Local Flood Modes in Paint.NET's Magic Wand tool. Understanding these two modes will help you control how pixel selections spread across an image, allowing you to select isolated objects or target specific colors across an entire canvas with precision.

What Is Flood Mode?

When using the Magic Wand (or Paint Bucket) in Paint.NET, Flood Mode determines how far the selection extends from the point you click. Based on the active Tolerance level, Paint.NET identifies pixels that match the color of the target pixel. Flood Mode then decides whether the selection should be restricted to connected areas or applied across the entire active layer.

Local Flood Mode (Contiguous Selection)

Local mode is the default setting for the Magic Wand. It functions as a contiguous selection tool.

  • How It Works: When you click a pixel, the selection expands outward, only including adjacent pixels that fall within the chosen tolerance. If the expansion encounters a boundary—such as an outline or a different color outside the tolerance limit—the selection stops.
  • Key Characteristic: Selected pixels must be physically connected to the point of origin. Disconnected regions of the exact same color will remain unselected.
  • Best Used For:
    • Isolating a single object from its background.
    • Selecting a specific, enclosed shape or section of an illustration.
    • Editing an area without affecting identical colors elsewhere in the image.

Global Flood Mode (Non-Contiguous Selection)

Global mode removes the requirement for pixels to be touching, functioning as a color-wide selection tool.

  • How It Works: When you click a pixel, Paint.NET scans the entire active layer (or current active selection) and selects every pixel that matches the targeted color within the chosen tolerance, regardless of its location on the canvas.
  • Key Characteristic: Pixels do not need to be connected to the clicked area. Islands of matching color separated by different colors will all be selected simultaneously.
  • Best Used For:
    • Removing a solid background that appears in multiple disconnected areas (such as the spaces inside letters or between limbs).
    • Replacing a specific color throughout an entire image or design.
    • Selecting line art or complex patterns across the entire canvas.

Quick Comparison

Feature Local Mode Global Mode
Pixel Connectivity Must be touching (contiguous) Does not need to be touching (non-contiguous)
Boundaries Blocked by non-matching colors Ignores boundaries
Scope Confined to the clicked region Affects the entire active layer
Primary Use Isolating single objects Canvas-wide color targeting

How to Switch Between Modes

You can switch the Flood Mode via the tool options bar at the top of the Paint.NET window whenever the Magic Wand is active:

  1. Click the Flood Mode dropdown in the toolbar.
  2. Select either Contiguous (Local) or Global.

Alternatively, you can temporarily invoke Global mode while the tool is set to Local by holding down the Shift key when you click on the image.
