How to Add Drop Shadow and Bevel in Paint.NET

Paint.NET does not include native tools for drop shadow and bevel effects, but you can easily add them using community-created plugins. This guide outlines how to download and install a standard plugin pack, followed by step-by-step instructions on applying drop shadow and bevel effects to text, shapes, or isolated graphics on transparent layers.

Step 1: Install the Necessary Plugins

The easiest way to get both effects is by installing the widely used BoltBait's Plugin Pack (or KrisVDM's Drop Shadow plugin).

  1. Close Paint.NET if it is currently running.
  2. Download a trusted plugin pack, such as BoltBait’s Pack, from the official Paint.NET forums.
  3. Extract the downloaded ZIP archive.
  4. Locate the .dll files (specifically DropShadow.dll and Bevel.dll or the installer executable provided with the pack).
  5. Copy the .dll files and paste them into your Paint.NET Effects directory, usually located at:
    C:\Program Files\paint.net\Effects
  6. Relaunch Paint.NET.

Step 2: Prepare Your Canvas

Both effects calculate edges based on transparency, so your subject must be isolated.

  1. Create a new layer by clicking Layers > Add New Layer (Ctrl + Shift + N).
  2. Add your text, icon, or shape onto this new, transparent layer. Do not merge it with the background layer.

Step 3: Add a Drop Shadow

  1. Select the layer containing your isolated element.
  2. Navigate to the top menu and select Effects > Object > Drop Shadow.
  3. In the plugin dialog, configure the following settings:
    • Offset X and Y: Controls the horizontal and vertical distance of the shadow from the object.
    • Shadow Blur Radius: Controls the softness or sharpness of the shadow's edges.
    • Shadow Opacity: Determines how dark or transparent the shadow appears.
    • Shadow Color: Select the color of the shadow (black is standard).
  4. Click OK to apply the shadow.

Step 4: Add a Bevel Effect

  1. Ensure the layer with your object is still selected.
  2. Navigate to Effects > Object > Bevel (or Effects > Selection > Bevel Selection depending on the specific plugin installed).
  3. Adjust the parameters:
    • Depth / Width: Controls how far into the object the beveled edge extends.
    • Light Angle: Dictates the direction of the virtual light source creating the highlights and shadows.
    • Highlight and Shadow Strength: Balances the contrast between the raised edge and the recessed edge.
  4. Click OK to render the 3D-style beveled edge.
