Paint.NET Eraser Tool Keyboard Shortcut

This guide explains how to quickly select the Eraser tool in Paint.NET using keyboard shortcuts. Mastering this single-key command speeds up your image editing workflow by eliminating the need to manually click through the toolbar whenever you need to remove pixels or create transparency.

The keyboard shortcut to select the Eraser tool in Paint.NET is the letter E.

Pressing E on your keyboard immediately activates the Eraser, regardless of which standard drawing or selection tool you are currently using. Once active, the cursor changes to an eraser icon, allowing you to wipe away content on the currently selected layer.

Useful Tips for Using the Eraser Tool

  • Adjusting Brush Width: You can rapidly increase or decrease the size of your eraser without touching the mouse. Press the ] (right bracket) key to increase the brush width and the [ (left bracket) key to decrease it.
  • Opacity and Transparency: The Eraser tool removes pixels down to complete transparency on standard layers. If you want to erase gradually, you can lower the opacity slider in the Colors window or change the layer blending properties.
  • Returning to Other Tools: To quickly switch away from the Eraser, use adjacent single-key shortcuts such as B for the Paintbrush, P for the Pencil, or S for the Rectangle Select tool.
