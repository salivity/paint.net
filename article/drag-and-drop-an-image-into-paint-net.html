Drag and Drop an Image into Paint.NET

Dragging and dropping an image file directly onto the Paint.NET workspace triggers an action prompt that gives you immediate control over how the file is imported. Instead of automatically replacing your current work or opening blindly, Paint.NET displays a dialog box asking whether you want to open the file as a completely new document or insert it as a new layer within your existing canvas. This mechanism allows you to quickly import assets without disrupting your active project.

The Action Prompt

When you drop an image file (such as a PNG, JPG, BMP, or WebP) onto an active canvas, Paint.NET displays a dialog box with three choices:

  • Open: Opens the dropped file as an entirely separate document in a new tab.
  • Add layer: Inserts the image as a new, separate layer directly on top of your currently active project.
  • Cancel: Closes the dialog and cancels the operation without making any changes.

Choosing "Open"

Selecting the Open option leaves your current project untouched and loads the dropped file into its own tab. The image appears in the thumbnail list along the top-right corner of the interface. This option functions identically to using File > Open from the top menu.

If you drop an image directly onto the top thumbnail bar rather than onto the canvas workspace, Paint.NET bypasses the dialog prompt entirely and automatically opens the file as a new document.

Choosing "Add Layer"

Selecting the Add layer option places the image on a newly created layer above the currently active layer in your open document.

  • Matching Canvas Sizes: If the dropped image has the exact same dimensions as your existing project, it aligns directly with the canvas boundaries.
  • Different Dimensions: If the dropped image is larger or smaller than your current canvas, Paint.NET retains the current canvas size. The dropped image will appear with selection handles active, allowing you to resize, move, or rotate the new layer immediately using the Move Selected Pixels tool. Portions of an imported image that exceed the current canvas borders will remain intact on that layer, though only the visible area within the canvas boundaries will be rendered.

Dragging Multiple Files

If you select multiple image files from your file manager and drop them onto the Paint.NET workspace at the same time, the program asks whether to apply your choice to all selected items. You can choose to open all files into separate tabs at once or stack all of them as individual layers within your active project.

Dragging When No Canvas is Open

If you launch Paint.NET and close the default blank canvas—or launch the application empty—dropping an image file onto the workspace opens the image immediately as a new document without displaying a prompt dialog.
