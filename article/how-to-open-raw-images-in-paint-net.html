How to Open RAW Images in Paint.NET

Paint.NET does not natively support camera RAW image formats like CR2, NEF, ARW, or DNG, but you can easily add this functionality by installing a specialized FileType plugin. This guide explains how to acquire the necessary RAW plugin, install it into the correct Paint.NET directory, and successfully open and edit uncompressed camera files on your computer.

Step 1: Download a RAW FileType Plugin

Because Paint.NET relies on an open plugin architecture, you need a plugin that interfaces with raw-processing libraries (such as LibRaw or dcraw).

  1. Visit the official Paint.NET Forum and navigate to the Plugin Releases section.
  2. Search for the RAW FileType plugin (commonly maintained as RawFile).
  3. Download the .zip archive containing the plugin files to your computer.

Step 2: Unblock and Extract the Files

Windows often blocks dynamic link library (.dll) files downloaded from the internet for security purposes.

  1. Right-click the downloaded .zip file and select Properties.
  2. If an Unblock checkbox appears near the bottom of the General tab, check it and click Apply, then OK.
  3. Extract the contents of the archive to access the RawFile.dll (or similarly named) file.

Step 3: Install the Plugin into Paint.NET

Make sure Paint.NET is closed before proceeding with the installation.

  1. Open File Explorer and navigate to your Paint.NET installation directory:
    • Standard Installation: C:\Program Files\paint.net\FileTypes
    • Microsoft Store Version: If you use the Store version, navigate to Documents\paint.net App Files\FileTypes (create the folder if it does not exist).
  2. Copy the extracted .dll file from your download folder and paste it into the FileTypes folder.
  3. If prompted for administrator permissions, click Continue.

Step 4: Open RAW Images in Paint.NET

  1. Launch Paint.NET.
  2. Click File in the top menu and select Open (or press Ctrl + O).
  3. In the file selection window, click the file format dropdown menu in the bottom-right corner. You will now see formats such as RAW Camera Image or specific extensions like .cr2, .nef, .arw, and .dng.
  4. Select your file and click Open.

Your camera's RAW file will render directly onto the canvas, ready for cropping, color adjustments, and further editing.
