How to Change Shape Fill Style in Paint.NET

In Paint.NET, changing the shape fill style allows you to customize the interior appearance of geometric objects using solid colors, outlines, or textured patterns. This guide provides a straightforward walkthrough on locating the shape tools, choosing the appropriate draw type, and adjusting fill styles using the tool options bar.

Step 1: Select the Shapes Tool

Open Paint.NET and select the Shapes tool from the Tools window on the left side of the screen, or press the shortcut key O on your keyboard.

Step 2: Locate the Shape Settings on the Toolbar

Once the Shapes tool is active, the top toolbar updates with settings specifically for drawing shapes. Look for two key settings:

  • Shape Draw Type (determines outline vs. fill)
  • Fill Style (determines the pattern inside the fill)

Step 3: Select the Shape Draw Type

Click the Shape Draw Type dropdown menu on the toolbar (by default, it displays an icon showing an outline). Choose one of the three available drawing modes:

  • Draw Shape Outline: Creates an empty shape with an outline using the Primary color.
  • Draw Filled Shape: Fills the interior of the shape using the Primary color without an exterior border.
  • Draw Filled Shape with Outline: Fills the interior using the Secondary color and renders an outline using the Primary color.

To enable any fill effect, you must choose either Draw Filled Shape or Draw Filled Shape with Outline.

Step 4: Change the Fill Pattern

Next to the Brush Width setting in the toolbar, locate the Fill dropdown menu. By default, this is set to Solid Color.

Click the Fill menu to view a list of built-in fill patterns. You can select from options such as:

  • Grid patterns (Checkerboard, Small Grid, Large Grid)
  • Line hatches (Horizontal, Vertical, Forward Diagonal, Backward Diagonal)
  • Textures (Polka Dot, Shingle, Trellis, Weave)

Step 5: Adjust Your Colors

The pattern and fill colors depend on the Colors palette (press F8 if it is not visible):

  • Primary Color: Controls the outline color and the foreground of the selected pattern.
  • Secondary Color: Controls the background fill of the selected pattern (or the solid fill if using the outline-plus-fill draw mode).

Click and drag on the canvas to draw your shape. As long as the vector control points are visible around your shape, you can freely change the fill style, draw type, colors, and brush width in real time before finalizing the shape.
