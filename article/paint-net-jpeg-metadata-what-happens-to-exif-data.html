Paint.NET JPEG Metadata: What Happens to EXIF Data?

When you edit and save a JPEG image in Paint.NET, the program generally preserves the existing EXIF (Exchangeable Image File Format) metadata, but it also modifies or discards specific data fields depending on how you handle the file. This guide explains how Paint.NET treats metadata during the JPEG saving process, which tags are automatically updated, and the situations where EXIF data can be completely lost.

Default Preservation of EXIF Tags

When you open an existing JPEG file containing metadata and save it using either Save (Ctrl+S) or Save As (Ctrl+Shift+S) in the JPEG format, Paint.NET retains the vast majority of the original EXIF block. Critical camera and capture details—such as shutter speed, aperture, ISO, focal length, camera make and model, date created, and GPS coordinates—are copied directly into the newly saved file.

Tags That Paint.NET Modifies

While the bulk of the metadata remains untouched, Paint.NET automatically updates or normalizes certain tags to maintain visual and technical consistency:

  • Orientation Tag: Digital cameras often write an orientation flag (e.g., indicating the camera was held vertically) rather than rotating the raw pixel data. When you open an image, Paint.NET reads this tag and physically rotates the pixel canvas so the image appears right-side up. When you save the file, Paint.NET resets the EXIF orientation tag to "Top-Left" (Normal/1) to prevent other image viewers from double-rotating the already corrected pixel data.
  • Software Tag: Paint.NET writes its application name and current version number into the EXIF "Software" tag to record the tool last used to modify the image.
  • Date Modified: Standard file system timestamps and specific EXIF modification timestamps are updated to the current date and time of the save operation.

Scenarios Where Metadata Is Completely Lost

Paint.NET does not retain EXIF data in all editing scenarios. Metadata will be stripped under the following conditions:

  • Copying and Pasting into a New File: If you copy an image or its layers and paste them into a newly created canvas (File > New), the metadata is discarded. Paint.NET treats a new canvas as a completely fresh document with no inherited EXIF attributes.
  • Converting File Formats: If you save a JPEG as a file type that does not support the same metadata standards (or where Paint.NET's file format encoder does not support passing EXIF tags), the data is removed.
  • Exporting Flattened Layers from Scratch: Creating a composition from multiple imported layers on an untitled canvas will result in an exported JPEG without the original source images' EXIF records.

Stripping Metadata Intentionally

Paint.NET does not include a native toggle in its standard JPEG configuration dialog to selectively strip metadata for privacy. If you need to remove sensitive information—such as embedded GPS location coordinates—before sharing an image, you must either copy the canvas into a new document before saving, use a dedicated metadata removal tool, or install a community-developed file-type plugin that provides a metadata-stripping option.
