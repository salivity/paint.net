How to Check Layer Dimensions in Paint.NET

In Paint.NET, every layer technically shares the exact pixel dimensions of the entire canvas. However, if you need to determine the specific pixel dimensions of the visible object or content residing on an individual layer, you can easily measure it using Paint.NET's built-in selection tools and the bottom status bar. This guide walks you through the quickest methods to find the exact width and height of any layer's content.

Method 1: Use the Magic Wand and Status Bar

The fastest way to measure the bounding box of non-transparent pixels on a layer is to invert an empty-space selection.

  1. Open the Layers window (press F7 if it is not visible) and click on the layer you want to inspect.
  2. Select the Magic Wand tool from the Tools window (or press S until the wand is selected).
  3. Set the Flood Mode in the top toolbar to Global.
  4. Click on any transparent area surrounding your layer's content.
  5. Invert the selection by pressing Ctrl + I. This snaps the selection exclusively around the visible pixels on that layer.
  6. Look at the Status Bar at the very bottom-left of the Paint.NET window. It will display the bounding box dimensions in pixels (formatted as width × height).

Method 2: Use the Move Selected Pixels Tool

If your layer's content is already isolated or contained within a specific area, you can read the dimensions directly using the transform tool.

  1. Select the layer in the Layers panel.
  2. Press Ctrl + A to select the entire canvas.
  3. Switch to the Move Selected Pixels tool (press M).
  4. Drag one of the selection handles slightly and snap it back, or press Ctrl + C followed by Ctrl + V.
  5. Read the pixel dimensions displayed in the bottom status bar, which indicates the bounding rectangle size of the active selection.

Method 3: Paste into a New Image

If you want to isolate the layer to confirm its dimensions and work with it separately:

  1. Select the layer in the Layers window.
  2. Use the Magic Wand (with inverted selection via Ctrl + I) or the Rectangle Select tool to select the content.
  3. Press Ctrl + C to copy the content to your clipboard.
  4. Press Ctrl + Alt + V (Paste into New Image). Paint.NET will automatically create a new canvas sized precisely to the copied pixel dimensions.
  5. Check the status bar at the bottom, or press Ctrl + R to open the Resize dialog to view the exact pixel width and height.
