Default Background Color in Paint.NET

When creating a new document in Paint.NET, understanding the default canvas settings is essential for managing layers and transparency. This article explains the default background color configuration applied to new projects, the technical structure of the initial canvas, and how to quickly adjust or remove it to suit your workflow.

The Default Canvas Configuration

By default, every new document created in Paint.NET opens with a solid white (#FFFFFF) background.

When you open the application or select File > New (or press Ctrl + N), Paint.NET prompts you to choose the canvas width, height, and resolution. Once confirmed, the program automatically generates a single layer titled Background that is completely filled with opaque white pixels.

Why Paint.NET Uses a White Background

Paint.NET initializes projects with a white layer to mimic a traditional blank sheet of paper, ensuring that basic drawing tools (such as brushes, pencils, and shapes) are immediately visible.

Even though the application sets the default Primary Color to Black and the Secondary Color to White in the Colors palette, the new document generation process ignores the active tool colors and always fills the initial "Background" layer with white.

Working with Transparency

Unlike some other digital imaging software, Paint.NET does not provide an option within the New Image dialog to start with a transparent canvas. If your project requires a transparent background (such as for PNG graphics, logos, or web assets), you can achieve it instantly through the following methods:

  1. Clear the Background Layer: Press Ctrl + A to select the entire canvas, then press the Delete key on your keyboard. This erases the white fill and reveals the gray-and-white checkerboard pattern representing transparency.
  2. Add a New Layer: Click the Add New Layer button in the Layers window, draw on the new transparent layer, and delete or uncheck the visibility of the original "Background" layer.
