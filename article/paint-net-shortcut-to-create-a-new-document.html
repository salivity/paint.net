Paint.NET Shortcut to Create a New Document

Opening a new blank canvas in Paint.NET can be done instantly without navigating through menus by using a simple keyboard command. This guide covers the standard keyboard shortcut used to generate a new document, the steps to configure the canvas size, and a useful tip for matching project dimensions to your clipboard contents.

The Primary Keyboard Shortcut

To create a new blank document in Paint.NET, press:

  • Ctrl + N

Step-by-Step Instructions

  1. Open Paint.NET on your computer.
  2. Press the Ctrl key and the N key simultaneously on your keyboard.
  3. A New dialog box will immediately appear on the screen.
  4. Specify your preferred canvas settings:
    • Pixel Size: Adjust the Width and Height values to define the digital dimensions.
    • Resolution: Set the pixels per inch or centimeter if you plan to print your work.
    • Maintain aspect ratio: Check this box if you want the width and height to scale proportionally.
  5. Press the Enter key or click the OK button to generate your new blank canvas.

Automatic Clipboard Sizing

If you copy an image or a screenshot to your clipboard prior to pressing Ctrl + N, Paint.NET will automatically detect the dimensions of that copied image. The dialog box will auto-populate with the exact width and height of the image on your clipboard. To instantly create a canvas that fits your copied graphic, simply press Ctrl + N followed immediately by Enter.
