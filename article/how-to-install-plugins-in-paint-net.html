How to Install Plugins in Paint.NET

Third-party plugins expand the functionality of Paint.NET by adding custom effects, adjustment options, and support for additional file formats. Installing these add-ons requires downloading the plugin package, extracting the necessary dynamic-link library (.dll) files, and placing them into the correct directory within your Paint.NET installation. This guide covers the complete, step-by-step process for both standard desktop and Microsoft Store installations.

Step 1: Download and Extract the Plugin

Most Paint.NET plugins are distributed via the official Paint.NET forum as compressed ZIP files.

  1. Download the plugin package from a trusted source.
  2. Right-click the downloaded .zip file and select Extract All.
  3. Open the extracted folder to locate the plugin files, which typically have a .dll file extension.

Step 2: Determine the Plugin Type

Paint.NET categorizes plugins into two main types:

  • Effects: Adds visual filters, adjustments, and rendering tools.
  • File Types: Adds support for loading and saving unsupported image formats (such as PSD, WebP, or SVG).

Look at the instructions included with the plugin or check the file name to identify whether it belongs in the Effects or FileTypes directory.

Step 3: Locate the Installation Directory

The folder location depends on how you installed Paint.NET.

For the Standard (Classic) Installer:

  1. Navigate to: C:\Program Files\paint.net\
  2. Inside, you will see subfolders named Effects and FileTypes.

For the Microsoft Store Version:

  1. Navigate to your user Documents folder: C:\Users\<YourUsername>\Documents\
  2. Open or create a folder named paint.net App Files.
  3. Inside that folder, create two subfolders if they do not already exist: Effects and FileTypes.

Step 4: Move the Plugin Files

  1. Copy the .dll file from your extracted download.
  2. Paste the file into the corresponding folder:
    • Effect plugins go into the Effects folder.
    • File format plugins go into the FileTypes folder.
  3. If prompted by Windows for administrator permissions, click Continue.

Step 5: Unblock the File (If Necessary)

Windows often blocks .dll files downloaded from the internet for security reasons.

  1. Right-click the newly pasted .dll file and select Properties.
  2. In the General tab, check the bottom section for a security warning that says, "This file came from another computer and might be blocked to help protect this computer."
  3. Check the Unblock box and click Apply, then OK.

Step 6: Restart Paint.NET

Close Paint.NET if it is currently running, then launch it again. The newly installed features will now be available:

  • Effects appear under the Effects or Adjustments menus.
  • File types appear automatically in the format dropdown list when opening or saving files via File > Open or File > Save As.
