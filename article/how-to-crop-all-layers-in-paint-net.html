How to Crop All Layers in Paint.NET

Cropping a multi-layer project in Paint.NET without flattening the image or losing individual layer data is straightforward because the software's canvas-cropping tools automatically apply globally across the entire document. This guide explains how to use the selection crop tool and the canvas resize feature to redefine the boundaries of your document while maintaining the structure, transparency, and order of every layer.

Method 1: Using Crop to Selection

The fastest way to crop all layers simultaneously to a specific area is by using the Crop to Selection command.

  1. Select the Tool: Choose the Rectangle Select tool from the Tools panel (or press the S key).
  2. Draw the Crop Area: Click and drag across the canvas to frame the area you want to keep. The specific layer currently highlighted in the Layers panel does not matter for this step.
  3. Apply the Crop: Navigate to the top menu, click on Image, and select Crop to Selection. Alternatively, press the keyboard shortcut Ctrl + Shift + X.

Paint.NET instantly resizes the entire document to the boundaries of your selection. All layers are cropped simultaneously to the exact same dimensions without being merged or flattened.

Method 2: Using the Canvas Size Tool

If you need to crop the document to exact pixel dimensions rather than a freehand selection, use the Canvas Size tool.

  1. Open Canvas Size: Click on Image in the top menu and select Canvas Size, or press Ctrl + Shift + R.
  2. Set New Dimensions: Enter your desired width and height values in pixels or absolute units. Uncheck Maintain aspect ratio if you need an arbitrary crop.
  3. Choose an Anchor Point: Use the Anchor grid to determine where the remaining image content will sit within the new dimensions (for example, choosing the center anchor trims the edges evenly on all sides).
  4. Apply Changes: Click OK.

Essential Tips to Keep Layers Intact

  • Do Not Press Delete: Pressing the Delete key while a selection is active only deletes pixels on the currently active layer rather than cropping the canvas. Always use Crop to Selection (Ctrl + Shift + X).
  • Preserve the Project Format: When saving your cropped document, save it as a Paint.NET file (.pdn) via File > Save As. Saving in formats like .jpg or .png will flatten all layers into a single background.
