How to Report Paint.NET Bugs and Crash Dumps

When Paint.NET encounters an unexpected error or sudden crash, it generates a detailed log file containing diagnostic data that helps the developer identify and fix the issue. This guide explains how to find your Paint.NET crash logs, gather essential system diagnostic details, and properly submit a bug report to the developer through official support channels.

1. Locate the Crash Log

When Paint.NET crashes, it usually attempts to save a crash log automatically. You can find this file using one of the following methods:

  • Desktop: In many cases, a file named pdncrash.1.log (or a sequentially numbered .log file) will be placed directly onto your Windows Desktop.
  • CrashLogs Folder: If the log is not on your Desktop, open the Windows Run dialog by pressing Windows Key + R, paste %LOCALAPPDATA%\paint.net\CrashLogs into the text box, and press Enter. Open the most recently dated text file in that directory.

2. Gather System Diagnostic Information

If the program is still open, or if you are reporting a non-fatal bug, collect your system diagnostics directly from Paint.NET:

  1. Open Paint.NET.
  2. Click the Gear icon (Settings) in the top-right corner.
  3. Select the Diagnostics tab on the left menu.
  4. Click Copy to clipboard.

This captures your exact Paint.NET version, Windows build, CPU architecture, and graphics hardware details without exposing personal information.

3. Submit the Report on the Official Forum

The primary and preferred way to report bugs and crashes to the developer (Rick Brewster) is through the official Paint.NET community forum.

  1. Navigate to the official Paint.NET forum at forums.getpaint.net.
  2. Create an account or sign in.
  3. Go to the Troubleshooting & Bug Reports section.
  4. Click Start new topic.
  5. Give your thread a descriptive title summarizing the problem (e.g., "Crash when applying Gaussian Blur on 16-bit image").
  6. In the post body, provide:
    • A step-by-step description of what you were doing when the issue occurred.
    • Whether the issue can be reproduced consistently.
    • The copied Diagnostics information.
    • The entire contents of your crash log pasted inside a [code] or [spoiler] block.

4. Alternate Reporting Method

If you cannot access the forum or if the crash log explicitly instructs you to do so, you can email the log file directly to the developer at contact@getpaint.net. Include a clear description of the steps leading up to the crash and attach the relevant .log file.
