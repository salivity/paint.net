Paint.NET Magic Wand Sampling Modes Explained

The Magic Wand tool in Paint.NET is a core selection feature that selects areas of similar color based on pixel data. When configuring how the tool reads colors across your canvas, Paint.NET offers two primary sampling modes: Layer and Image. Understanding the difference between these two modes ensures you can make accurate selections whether you are working on an isolated element or a complex, multi-layered project.

Layer Sampling Mode

Layer mode is the default sampling setting in Paint.NET. When set to Layer, the Magic Wand only samples pixels from the currently active layer selected in the Layers window.

  • How it works: Any pixels on other visible layers—above or below the active layer—are completely ignored during color evaluation.
  • When to use it: Use Layer mode when you need to select or isolate content on a single layer without interference from backgrounds, overlays, or adjustments on separate layers. It also allows you to make clean selections of transparent boundaries within an isolated layer.

Image Sampling Mode

Image mode changes the tool’s behavior to evaluate the composite, flattened view of your canvas.

  • How it works: Instead of limiting its color detection to the active layer, the Magic Wand reads the final rendered pixel colors created by all currently visible layers combined. However, the resulting selection itself is still applied only to the active layer.
  • When to use it: Use Image mode when your visual edges are created by multiple overlapping layers (such as textures, shading layers, or background art) and you want to select an area based on what is visually displayed on screen without having to merge your layers first.

Complementary Selection Controls

To further refine how the Magic Wand operates within these sampling modes, adjust the following related settings on the toolbar:

  • Tolerance: Dictates how strictly the tool matches the target color. A lower percentage requires a near-exact color match, while a higher percentage selects a broader spectrum of adjacent shades.
  • Flood Mode: Determines whether the selection is Contiguous (only adjacent, connected pixels matching the sampled color) or Global (every matching pixel across the entire canvas, regardless of location).
